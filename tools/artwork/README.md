# Sprint 4 mascot artwork

Created with the built-in `image_gen.imagegen` tool; no CLI/API key or stock artwork was used.

- Original generated output copied into this checkout: `tools/artwork/chase-mascots.png`.
- Website asset: `bck_img/chase-mascots.webp`, 1200×800, 114,160 bytes. Converted with Sharp for delivery size; the original PNG is retained here and is excluded from the website build allowlist.

> Use case: stylized-concept illustration for the existing Billa Chuha game homepage. Create one premium playful editorial game illustration, landscape 3:2 composition. Three original animal mascots in a lively chase across a cozy overhead kitchen arena: a clever small warm-gray rat holding a golden cheese wedge in front, an orange tabby cat chasing in the middle, a larger floppy-eared blue-gray dog bounding behind. Expressive confident faces, friendly rivalry, rounded sculpted shapes, slightly grainy hand-painted 3D clay illustration, warm directional light, deep forest green background (#101812), pale lime accents (#c5e66b), apricot orange and muted sky blue matching the roles. Make all three characters clearly visible with generous breathing room and a few small kitchen floor tiles, table legs, cheese crumbs. Full characters contained within image; energetic curved movement but clean uncluttered silhouette. Artwork only, no lettering, no UI, no watermark, no logos. This is a marketing illustration, not a literal gameplay screenshot. Opaque forest-green background.
